# CC5002-2  Desarrollo de Aplicaciones Web - Otoño 2025

## Página web para mostrar actividades recreativas

La idea de este proyecto es poder mostrar en una aplicación web que permita gestionar actividades recreativas, cuenta con una portada donde hay enlaces a otras páginas para:

- Agregar actividades
- Ver listado de actividades (ahora con lista de comentarios)
- Ver estadisticas

Lo de arriba de implemento con flask y no se puede ver a menos que se corra flask, para esta tarea se implementó evaluar actividades con nota del 1 al 7 y se prueba corriendo el archivo Tarea4Application con Java.

## Decisiones de implementación tomadas (Tarea 4)

Para esta tarea, se implemento la nueva funcionalidad de mostrar una interfaz con el listado de actividades realizadas con Java, donde se agregó una columna de notas y otra para poder evaluar, para esto se ocupo bastante el auxiliar del curso para instalar el framework Spring Boot y luego hacer las llamadas asincronas con JS fetch, y para los HTML's se ocupa thymeleaf.
